>[!question] Che cos'è un pattern?

> Un design pattern è una *soluzione generale* ad un ***problema ingegneristico ricorrente***.

Un design pattern ***non è*** una soluzione già pronta ad un problema.
- È una ***descrizione astratta*** di come un certo tipo di problema può essere risolto

## Parallel Programming Patterns
---
>[!example] Patterns
> - [[Embarrassingly Parallel]]
> - [[Partition]]
> - [[Partition#Master-Worker Paradigm|Master-Worker]]
> - [[Stencil]]
> - [[Reduce]]
> - [[Scan]]

Un ***pattern di programmazione parallela*** definisce:
- Un partizionamento dei dati di `input`.
- Una struttura di comunicazione tra i *task* paralleli.

I pattern di programmazione parallela possono aiutare a definire ***algoritmi efficienti***.
- Molti problemi possono essere risolti utilizzando **uno o più pattern**.
